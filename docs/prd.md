# 需求文档

## 1. 应用概述

### 1.1 应用名称
实时文本预览器（代码叶 Codeleaf）

### 1.2 应用描述
一个集 Discord 风格富媒体语法解析、标准与扩展 Markdown 渲染、代码高亮、文本查找与替换、快捷输入联想、自定义模板存储与多格式导出于一体的实时文本编辑与预览工具。支持桌面端左右分栏与自由拖拽调节，移动端支持编辑与预览单视图切换。应用深度支持 Discord 格式特性（嵌套文本样式、剧透遮罩、单行/多行引用、用户/身份组/频道实体标签渲染、自定义静态与动态表情解析），并在编辑区提供快捷格式化与「@/#/:」联想输入补全能力。整体采用单 HTML 文件（text-previewer.html）形态封装交付，无需外部构建工具即可在浏览器中独立直接运行。

## 2. 用户与使用场景

### 2.1 目标用户
Discord 社区运营者、Bot 开发者、内容创作者、排版设计人员、文档编辑人员等需要在多端边写边看富文本、代码排版及 Discord 专属格式渲染效果的用户。

### 2.2 核心使用场景
- 边编辑 Discord 格式文本与 Markdown 语法，边实时查看复合嵌套样式、剧透遮罩、引用块及实体标签渲染效果
- 在编辑区输入「@」、「#」或「:」快速触发联想下拉菜单，一键补全用户、身份组、频道标记或自定义表情代码
- 点击预览区中的剧透遮罩（Spoiler），自由切换遮盖与展示状态
- 选中文本后点击工具栏一键包裹加粗、斜体、下划线、删除线、剧透、行内代码或引用块标记
- 编写包含多种主流编程语言的代码片段，实时查看语法着色代码块并一键复制
- 在分栏模式下双栏所见即所得对照核对排版，或切换移动端视图检查不同视口下的排版表现
- 将排版完成的预览成果导出为高清 PNG 长图、Markdown（.md）或纯文本（.txt）文件
- 通过单文件（text-previewer.html）直接在浏览器中离线或本地加载使用完整功能

### 3.2 功能说明

#### 3.2.1 顶部导航栏

##### 3.2.1.1 品牌与状态展示
- 标题与品牌标识清晰呈现。
- 字数统计徽标：实时统计当前编辑区字符总量，窄屏下启用防换行保护。

##### 3.2.1.2 视图切换控制组
- 桌面端视口（宽度≥768px）：提供「分栏」、「编辑」、「预览」三种视图模式切换，默认处于分栏模式。
- 移动端视口（宽度<768px）：仅保留「编辑」与「预览」单视图切换，默认展示编辑视图。
- 响应式切换处理：视口宽度自桌面端缩小至移动端断点时，若处于分栏模式，自动回退至「编辑」单视图。

##### 3.2.1.3 快捷操作与模版管理
- 撤销与重做：记录文本变更、格式插入、替换及补全历史，支持快捷撤销与重做。
- 模版库面板：提供「预设模板」与「自定义模板」分类展示，支持点击应用或删除自定义模板。
- 保存为自定义模板：支持将当前编辑区内容及格式持久化保存至后端存储，成功后同步至模版库。

#### 3.2.2 编辑区

##### 3.2.2.1 自适应格式工具栏与一键包裹
- 文本样式快捷格式化：
  - 加粗（`**text**`）、斜体（`*text*`）、下划线（`__text__`）、删除线（`~~text~~`）、剧透遮罩（`||text||`）。
  - 选中文本操作：选中文本时点击对应按钮，自动使用相应标记符号包裹选中文本；未选中文本时点击，光标处插入占位标记并将光标置于标记中心。
- 块级与代码快捷插入：
  - 行内代码（`` `code` ``）与多行代码块（` ```lang
code
``` `）。
  - 单行引用（`> text`）与多行引用（`>>> text`）。
  - 表格、纯文本块、任务清单、分栏布局、高亮块快捷模板插入。
- 工具栏自适应与吸顶：宽度变窄时自动将低优先级项目折叠收纳至「更多」下拉菜单，向下滚动时吸顶常驻。

##### 3.2.2.2 输入联想补全菜单
- 触发机制：
  - 输入 `@` 时触发提及联想下拉菜单，列出常用用户（`<@id>`）和身份组（`<@&id>`）预设选项。
  - 输入 `#` 时触发频道联想下拉菜单，列出常用频道（`<#id>`）预设选项。
  - 输入 `:` 时触发表情联想下拉菜单，列出预设静态表情（`<:name:id>`）与动态表情（`<a:name:id>`）。
- 交互与补全：
  - 支持键盘上下键选择、Enter 键或鼠标点击确认补全。
  - 补全后自动将对应的 Discord 实体语法插入光标位置并关闭菜单，支持 Esc 键手动关闭。

##### 3.2.2.3 查找与替换面板
- 检索与定位：输入关键词实时统计数量，支持上/下一个匹配项循环跳转，编辑区自动同步滚动定位。
- 预览联动与替换：预览区同步高亮匹配词；支持单处替换与一键全部替换，变更自动推入撤销历史栈。

##### 3.2.2.4 文本输入与独立滚动
- 支持多行实时输入，编辑区具备独立纵向滚动条，内容变更即时同步至预览画布。
- 空状态展示简约引导图形与 Discord Markdown 语法示例提示。

#### 3.2.3 布局与分栏控制

##### 3.2.3.1 桌面端分栏与拖拽
- 桌面端视口下编辑区与预览区呈左右双栏分布，中央分割条支持鼠标拖拽调节左右宽度比例（20%~80%）。

##### 3.2.3.2 移动端单视图呈现
- 移动端视口下隐藏分割条，通过顶部导航栏「编辑」与「预览」按钮进行全屏切换。

#### 3.2.4 预览区

##### 3.2.4.1 工具栏与导出控制组
- 表格紧凑模式开关：一键开启或关闭预览区全部表格的紧凑排版。
- 多格式导出：支持导出高清 PNG 长图（导出期间覆盖骨架屏动效）、导出 Markdown（.md）文档、导出纯文本（.txt）文件。

##### 3.2.4.2 预览渲染画布
- Discord 文本样式与复合嵌套渲染：
  - 准确解析并支持加粗、斜体、下划线、删除线的任意两两或多重复合嵌套（如 `**__text__**`、`~~*text*~~` 等）。
  - 剧透遮罩（Spoiler）：解析 `||text||` 语法，渲染为带有模糊效果或深色遮罩的块；默认隐藏内容，用户点击遮罩后切换为清晰展示状态，再次点击恢复隐藏。
- Discord 实体与富媒体标记解析：
  - 用户提及（`<@id>`）与身份组提及（`<@&id>`）：解析为 Discord 风格的浅蓝/彩色半透明高亮交互标签，鼠标悬停呈现轻微微调反馈。
  - 频道提及（`<#id>`）：解析为带有前缀井号图标的专用交互标签。
  - 自定义表情：解析静态表情（`<:name:id>`）与动态表情（`<a:name:id>`），准确提取对应图片资源并以与行内文字匹配的尺寸内联渲染。
- 引用块与代码块解析：
  - 单行引用（`> `）：渲染为带左侧竖向强调线条的引用容器。
  - 多行引用（`>>> `）：将后续全部内容解析为整体连续引用块。
  - 行内代码与多行代码块：行内代码渲染为灰色底色胶囊；多行代码块根据指定语言高亮着色，显示行号，单行过长支持横向滚动，右上角提供一键复制代码按钮（点击反馈持续 1.5 秒）。
- 容错降级展示：对于不规范、闭合缺失或无法解析的格式语法，自动降级按纯文本原样安全转义呈现，杜绝页面排版异常或脚本错误。
- 预览区独立滚动与空状态：具备独立纵向滚动条；无内容时展示统一空状态图形。

##### 3.2.4.3 响应式画布尺寸控制区
- 默认选中「iPhone SE」（375×667），支持自定义输入宽高度数值，提供自适应缩放指示。

## 4. 业务规则与核心逻辑

### 4.1 Discord 语法解析与渲染规则
- 复合嵌套解析规则：按照规范正则与 AST 解析顺序，支持 `**`（粗体）、`*`（斜体）、`__`（下划线）、`~~`（删除线）自由嵌套，样式属性叠加生效。
- 剧透遮罩（Spoiler）交互规则：`||内容||` 语法渲染为带交互状态的遮罩元素，初始状态为遮盖（模糊或纯色遮挡），点击事件仅在该元素内部切换状态，不影响周围文本排版。
- 实体与表情转换规则：
  - 匹配 `<@!?[0-9]+>` 或 `<@&[0-9]+>` 转为提及标签。
  - 匹配 `<#[0-9]+>` 转为频道标签。
  - 匹配 `<:([a-zA-Z0-9_]+):([0-9]+)>` 解析为静态图片，匹配 `<a:([a-zA-Z0-9_]+):([0-9]+)>` 解析为动态 GIF 图片。
- 引用层级规则：`> ` 仅影响当前段落或紧随的单行；`>>> ` 影响从该标记开始直至文本末尾的全部后续段落，将其归入同一引用容器。
- 容错降级规则：未闭合的语法标记（如单侧 `**`、格式错误的实体 ID 等）不作为标签解析，直接作为字面文本渲染，防止破坏文档 DOM 结构。

### 4.2 编辑区快捷格式化与联想补全规则
- 工具栏包裹逻辑：若选区存在文本，点击加粗/斜体/剧透等按钮直接在选区前后添加配对语法标记，光标移动至包裹后的文本末尾；若选区为空，插入占位标记并将光标定位在中间。
- 联想触发规则：当在空行、行首或空格后输入 `@`、`#` 或 `:` 字符时立即弹出联想浮层；光标移出或输入不匹配内容时自动隐藏联想浮层；选中项目后将对应语法片段完整写入。

### 4.3 代码块与复制规则
- 优先调用剪贴板接口写入代码文本，权限受限时自动降级采用临时节点命令复制；点击后展示「已复制」反馈，持续 1.5 秒后复原。

### 4.4 单文件交付与环境规范
- 整体应用所有 HTML、CSS 样式、JavaScript 逻辑均打包内联于单一 `text-previewer.html` 文件中，无外部构建依赖，浏览器双击即可完整运行。

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 输入未闭合的剧透遮罩（如 `||abc`） | 容错降级，按普通纯文本展示字面符号，不破坏后续内容排版 |
| 实体标记中的 ID 格式错误或包含非法字符 | 判定为非合法实体标记，按纯文本原样转义输出 |
| 自定义表情图片资源加载失败或地址不可达 | 降级显示表情名称文字（如 `:name:`）或兜底图片占位符 |
| 输入 `@`、`#`、`:` 后无匹配的联想项目 | 联想菜单显示「无匹配结果」或自动平滑收起，不阻断正常键入 |
| 在快速连续键入时触发联想菜单 | 联想菜单根据最新光标后输入内容实时动态过滤，无卡顿闪烁 |
| 剪贴板权限受限 | 自动调用降级方案完成代码块或文本写入 |
| 保存自定义模板时名称为空 | 提示「请输入模板名称」，阻止提交 |
| 分栏拖拽至极端尺寸（20% / 80%） | 界面元素保持自适应，工具栏自动折叠溢出项，预览画布保持等比缩放适配 |

## 6. 验收标准

1. 应用以单个 `text-previewer.html` 文件交付，无需任何依赖与构建步骤即可在浏览器中直接运行全部功能
2. 编辑区输入 `**粗体**`、`*斜体*`、`__下划线__`、`~~删除线~~` 及其复合嵌套语法，预览区能准确无误地渲染出对应样式的层叠效果
3. 编辑区输入 `||剧透内容||` 语法，预览区渲染为遮罩状态；点击遮罩可切换为清晰内容，再次点击可重新遮盖
4. 编辑区输入 `<@id>`、`<@&id>`、`<#id>`，预览区能渲染为高亮交互标签；输入 `<:name:id>` 与 `<a:name:id>` 能正确渲染为静态与动态表情图片
5. 编辑区输入单行引用 `> text` 与多行引用 `>>> text`，预览区能分别按单行与多行容器样式正确渲染
6. 选中文本后点击工具栏加粗、斜体、剧透等按钮，能自动完成语法符号的一键包裹
7. 在编辑区输入 `@`、`#`、`:` 字符，能准确唤出对应用户/身份组、频道或表情的联想下拉菜单，支持键盘选择并一键补全
8. 输入不规范或未闭合的语法时，预览区自动按纯文本原样安全呈现，不发生页面崩溃或排版错乱
9. 预览区代码块右上角点击复制按钮，可将纯文本代码成功写入剪贴板并呈现 1.5 秒「已复制」反馈
10. 页面支持桌面端分栏拖拽与移动端（<768px）单视图切换，支持自定义模板存储及导出 PNG、Markdown、纯文本文件
